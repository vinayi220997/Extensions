# VidPull / VidSnag releases

Each zip is the ready-to-install extension for that version (tests left out). To install: unzip it, open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select the unzipped folder.

| Zip | Version | Highlights |
|---|---|---|
| `vidpull-v3.1.1-extension.zip` | 3.1.1 | Fixes the line-218 warning in the offline-licence check, the replay of early AJAX finds, and video size on DRM files |
| `vidpull-v3.1.0-extension.zip` | 3.1.0 | DRM detection and reporting (DASH, HLS, EME, encrypted MP4); AJAX/JSON detection; more formats; MP4/HLS/DASH/Other/Audio/DRM filters |
| `vidpull-v3.0.0-extension.zip` | 3.0.0 | Renamed to VidPull with orange branding; one sidebar at a time; Close button in Mini; icons follow the theme colour; app-shell pages pushed aside |
| `vidsnag-v2.2.0-extension.zip` | 2.2.0 | Page sidebar with Max / Mini / Auto-hide and icon-only controls |
| `vidsnag-v2.1.0-extension.zip` | 2.1.0 | Sorting, global "Always" defaults, pause/resume, sidebar modes |
| `vidsnag-v2.0.0-extension.zip` | 2.0.0 | Sidebar/PiP, settings, export/import, addons, right-click menus, saved links, link refresh, universal detection |
| `vidsnag-v1.0.0-extension.zip` | 1.0.0 | First build: popup, network and DOM detection, HLS/DASH download, settings, history |

Before installing VidPull 3.x, remove VidSnag (1.x–2.x) from Chrome. Your settings carry over if you export them in VidSnag and import them in VidPull (Settings › Backup).
